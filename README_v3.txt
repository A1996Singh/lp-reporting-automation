  XDRIVES LP REPORTING AUTOMATION  v3  —  COMPLETE GUIDE
══════════════════════════════════════════════════════════════════

FOLDER STRUCTURE (set up exactly like this on your machine)
────────────────────────────────────────────────────────────
  LP_Automation\
  │
  ├── lp_report_automation.py      ← Run this every quarter
  ├── LP_Report_Template_v3.docx   ← Word template (ready to use)
  │
  ├── CAS_Data\
  │   └── test_NAV.xlsx            ← Your quarterly CAS Excel
  │
  └── Output_PDFs\                 ← Auto-created; named PDFs land here


STEP 1 — INSTALL ONCE
───────────────────────
  Open Command Prompt (cmd) and run:

    pip install openpyxl python-docx pywin32
    python Scripts\pywin32_postinstall.py -install

  Requirements: Python 3.8+, Microsoft Word, Microsoft Outlook


STEP 2 — EACH QUARTER: UPDATE TWO LINES
─────────────────────────────────────────
  Open lp_report_automation.py and change:

    CAS_FILE      = r"CAS_Data\your_new_CAS_file.xlsx"
    QUARTER_LABEL = "Q2 2026"


STEP 3 — RUN
──────────────
  Open Outlook first (keep it open). Then in cmd:

    python lp_report_automation.py

  Per LP the script will:
    ✅ Read the LP row from your CAS Excel
    ✅ Fill LP_Report_Template_v3.docx with their personal data
    ✅ Convert to PDF → saved as: ABC_Holdings_LLC_Q1_2026.pdf
    ✅ Create an Outlook Draft with PDF attached and email pre-filled

STEP 4 — REVIEW AND SEND
──────────────────────────
  Go to Outlook → Drafts.
  Check each email — recipient, CC, attachment, body.
  Send manually. Nothing goes out automatically.


══════════════════════════════════════════════════════════════════
  ★  ADDING YOUR COMPANY LOGO (OPTIONAL — BOTTOM RIGHT)
══════════════════════════════════════════════════════════════════

This is a one-time setup in Word. Once done, every future PDF
generated by the script will include the logo automatically.

STEP-BY-STEP:

  1. Open LP_Report_Template_v3.docx in Microsoft Word.

  2. Click the "Insert" tab in the top ribbon.

  3. Click "Header & Footer" → "Footer" → "Edit Footer".
     (The footer area appears at the bottom of the page.)

  4. Press Tab twice to move the cursor to the RIGHT side of
     the footer (the footer has 3 tab stops: left, center, right).

  5. Click "Insert" → "Pictures" → "This Device…"
     Browse to your company logo file (PNG or JPG recommended).
     Select it and click Insert.

  6. Click on the logo image to select it.
     In the "Picture Format" tab that appears:
       • Set Height to 0.5"  (or 0.6" — whatever fits)
       • Set Width proportionally (tick "Lock aspect ratio")
       • Right-click the image → "Wrap Text" → "In Line with Text"

  7. Click "Close Header and Footer" in the ribbon.

  8. Save the file (Ctrl+S). Keep the filename exactly:
       LP_Report_Template_v3.docx

  9. Run lp_report_automation.py as normal.
     The logo will appear at bottom-right of every LP's PDF.

  TIP: If you want the logo at the TOP RIGHT instead, use the
  Header (step 3 → Header → Edit Header) and follow the same steps.

  TIP: To keep the logo consistent across all PDFs without any
  manual changes each quarter, do NOT put the logo directly in
  the document body — always use the Header/Footer area, since
  the script only replaces {{TOKEN}} fields in body paragraphs
  and table cells. Header/Footer content is left untouched.


══════════════════════════════════════════════════════════════════
  TEMPLATE TOKENS REFERENCE
══════════════════════════════════════════════════════════════════

  {{ENTITY}}               Fund entity name (large title + sub-header)
  {{DATE}}                 Quarter end date (e.g. March 31, 2026)
  {{INVESTOR_NAME}}        Investor / LP name
  {{INVESTED_CAPITAL}}     Invested capital amount

  QTD
    {{QTD_BEGINNING_NAV}}      Beginning Net Asset Value
    {{QTD_CHANGE_UNREALIZED}}  Change in Unrealized Appreciation/Dep
    {{QTD_RETURN_OF_CAPITAL}}  Return of Capital
    {{QTD_RETURN_ON_CAPITAL}}  Return on Capital
    {{QTD_ENDING_NAV}}         Ending Net Asset Value

  YTD  (same fields, YTD_ prefix)
  ITD / Since Inception  (same fields, ITD_ prefix)
    {{ITD_CONTRIBUTIONS}}      Contributions - Class A (ITD only)

  ⚠ Do NOT rename or delete any {{TOKEN}} — the script replaces
    them at runtime. If a token is missing, that cell stays blank.


══════════════════════════════════════════════════════════════════
  TROUBLESHOOTING
══════════════════════════════════════════════════════════════════

  "PDF conversion failed"
    → Close all open Word windows, then rerun the script.
    → Ensure Microsoft Word (desktop) is installed.

  "Outlook draft failed / pywin32 error"
    → Outlook must be open and signed in before running.
    → Rerun: pip install pywin32
    → Rerun: python Scripts\pywin32_postinstall.py -install

  Numbers show as "-" when they should have values
    → Check COLUMN_MAP in lp_report_automation.py
    → Headers in CAS Excel must match exactly (including spaces).
